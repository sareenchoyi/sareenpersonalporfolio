Agentic finance / evaluation lab

SpendOS

A policy engine for non-custodial AI-agent wallets, built around a sharper question: can automated spending remain bounded when agents retry, collaborate, and encounter hostile inputs?

Launch live demoExplore a trace
01 — System shape

Rules before transactions.

SpendOS separates policy decisions from payment execution. Every request is evaluated against the agent identity, recipient allowlist, per-transaction limit, period budget, and request identity before anything can be approved.
